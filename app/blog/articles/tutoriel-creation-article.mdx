# Pour créer un article, il faut suivre les étapes suivantes :

## 1. Créer un fichier Markdown (nom-article.mdx)

dans le dossier suivant :

```
app/blog/articles/nom-article.mdx
```

## 2. Remplir la partie supérieure du fichier avec les informations suivantes :

```
---
- title: "Titre de l'article"
- date: "Date de l'article" (format: YYYY-MM-DD)
- category: "Catégorie de l'article" (particuliers, aides-etat, societe, passer-au-solaire, technologie-solaire, pionniers-energie-solaire)
- image: "/assets/blog/dossier-de-l-article-concerné/image-article.png" (chemin vers l'image de l'article)
- draft: "true" (true pour garder l'article en brouillon et qu'il soit non visible sur le site, sinon ne rien mettre car false par défaut)
---
```
